# TDS Squads

Squad formation (spiral offsets), decisions and roaming. Pure C#, EditMode-tested.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.tds-squad#<branch-or-tag>
```

## Runtime
- `SquadFormation`
- `SquadDecision`
- `SquadRoam`
