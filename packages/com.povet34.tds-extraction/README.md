# TDS Extraction

Extraction-loop sims: board/stay progress and win/lose outcome evaluation. Pure C#, EditMode-tested.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.tds-extraction#<branch-or-tag>
```
