# TDS Camera Juice

Camera follow, shake, zoom, follow-position and hit-stop. Pure C#, EditMode-tested.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.tds-camera#<branch-or-tag>
```

## Runtime
- `CameraFollow`
- `CameraShake`
- `CameraZoom`
- `FollowPosition`
- `HitStop`
