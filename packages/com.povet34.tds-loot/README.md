# TDS Loot

Loot economy sims: carried wallet and drop chance/amount rolls. Pure C#, EditMode-tested.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.tds-loot#<branch-or-tag>
```

- `LootDrop`
