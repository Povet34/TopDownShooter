# TDS Combat FX

Breakable health, explosion model and low-health vignette. Pure C#, EditMode-tested.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.tds-combat-fx#<branch-or-tag>
```
