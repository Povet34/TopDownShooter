# TDS Spawning

Spawn tables, weighted selection, monster defs and wave sequencing. Pure C#, EditMode-tested.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.tds-spawning#<branch-or-tag>
```

## Runtime
- `SpawnTable`
- `SpawnSelection`
- `MonsterDef`
- `MonsterSpawner`
- `WaveSequencer`
