# Grid Inventory

Tarkov/Diablo-style multi-cell grid inventory: place/auto-place/rotate/remove with bounds and overlap checks. Pure C#, EditMode-tested, no external dependencies.

Pure C# (only UnityEngine), no external package dependencies. Types live in the `TDS.Core` namespace.

## Install (Unity Package Manager → Add from git URL)

```
https://github.com/Povet34/EscapeFromDesertPlanet.git?path=/packages/com.povet34.grid-inventory#<branch-or-tag>
```
